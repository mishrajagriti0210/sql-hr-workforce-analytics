# SQL HR Workforce Analytics

## Project Overview
A SQL-based HR analytics mini project focused on workforce composition, employee information, salary, performance, attendance, and hiring patterns.

## Business Objectives
- Understand workforce distribution across departments and locations.
- Analyze salary and performance patterns.
- Review attendance and employee status.
- Explore hiring trends over time.
- Convert HR data into useful workforce observations.

## Database Structure
The project uses four related tables:
- `Departments`
- `Locations`
- `Employees`
- `Performance`

## SQL Concepts Practiced
- Filtering, sorting, and aggregate functions
- GROUP BY and HAVING
- Joins across related HR tables
- CASE expressions
- Subqueries and CTEs
- Window functions

## Analysis Areas
- Employee headcount by department and location
- Salary comparisons
- Performance and attendance analysis
- Hiring trends
- Employee status and workforce composition

## Business Considerations
Salary differences should be interpreted alongside job level and role composition. Performance and attendance differences are descriptive findings and should be investigated further before drawing causal conclusions.
